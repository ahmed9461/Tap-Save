# Tap Save — Brand Identity

## Brand idea

Tap Save should feel like a quiet system utility: fast, clean, private, and always ready without demanding attention.

**Core phrase:** `Tap. Save. Done.`

## Personality

- Fast
- Minimal
- Calm
- Precise
- Private
- Modern

Avoid visual language that feels like an ad-heavy “video downloader” app.

## Logo / app icon concept

Primary concept: a single geometric mark combining:

1. a downward save arrow;
2. a subtle tap/click ripple;
3. a rounded container that feels native to Android.

The mark should remain readable at launcher-icon size and as a tiny floating overlay button.

Do not imitate Instagram's gradient/logo or use another platform's trademark as the app identity.

## Color system

### Primary
- **Tap Mint:** `#35E6A7`
- Use for the active save action, progress highlight, and key interactive accents.

### Surfaces
- **Deep Ink:** `#0B1018`
- **Graphite:** `#151C27`
- **Soft White:** `#F5F7FA`
- **Muted Slate:** `#9099A8`

### State colors
Use Android/Material semantic state colors where possible rather than inventing many custom colors. Keep the product visually restrained.

## UI direction

- Dark-first appearance.
- Rounded geometry.
- Very little text during the primary browsing flow.
- Floating control should be a compact circle/pill with clear iconography.
- Progress should preferably be expressed as a ring around the main icon rather than a separate window.
- Success state: quick checkmark / subtle haptic acknowledgement.
- Error state: compact retry affordance, not a modal interruption.

## Typography

Use Android system typography / Material typography for the app UI. Avoid bundling a custom font unless it creates a clear product benefit.

## Floating button states

- Idle: download arrow.
- Resolving: subtle indeterminate ring.
- Downloading: determinate progress ring.
- Success: checkmark, then return to idle.
- Error: retry/exclamation state.
- Hidden/snoozed: no persistent screen obstruction.

## Voice

Short, human, functional.

Good:
- `Saved`
- `Downloading…`
- `Try again`
- `Share a Reel to Tap Save`

Avoid:
- long explanatory popups;
- marketing copy;
- unnecessary confirmation dialogs.

## Icon deliverables later

When the core technical flow is proven, create:

- Android adaptive icon foreground;
- adaptive icon background;
- monochrome/themed icon;
- high-resolution source artwork;
- compact overlay glyph derived from the same mark.

Do not finalize detailed icon artwork before the technical spike unless it blocks packaging/testing.
