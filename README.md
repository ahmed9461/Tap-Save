# Tap Save

Tap Save is a lightweight personal Android app for saving videos while browsing supported apps, starting with Instagram Reels.

## Product goal

The core interaction should feel almost invisible:

**Browse → like a reel → tap the floating download button → keep browsing.**

The app is intended for personal use, with no ads, tracking, account system, or unnecessary background activity.

## Initial scope

- Android only.
- Instagram Reels first.
- Floating download button shown only when useful.
- Fast download with visible progress.
- Save into a predictable local media folder.
- Share-to-Tap-Save fallback when direct detection is unavailable.
- Architecture prepared for additional platforms later without implementing them now.
